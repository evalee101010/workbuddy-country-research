# 逐国公开需求信号研究 SOP

## 1. 开始前先写清楚

确认国家、run ID、研究窗口、执行者，以及本轮只回答公开需求信号，不回答市场规模、国家排名、政策合规或我方制胜能力。

Country Config 是起点，不是结论。先核对：核心语言、探索语言、迁移走廊语言、一级行政区、主流角色、任务家族、竞品别名、公开访问边界。本地研究者如发现配置不合适，应先记录理由再调整配置。

## 2. Local Source Discovery

至少扫描五组渠道：

1. 全球产品/技术社区；只作技术补充或主题发现。
2. 当地 AI、专业与行业社区。
3. 当地主流社交、图文、短视频、问答和职业平台，即当地“小红书类”入口。
4. 当地投诉、评价、App 商店和 SaaS 目录。
5. 侨民、外籍人士和迁移走廊社区。

每个平台写清本地活跃证据、受众、可保存字段、地域颗粒度、公开/机器访问方式、权限和主要偏差。没有当轮证据时保持 `Candidate-Validate`。

## 3. 查询包执行

- A：产品名/别名 + 具体工作任务 + review/experience/problem 等实际使用词。
- B：工作任务 + pain/slow/manual/need/help 等需求词，不要求出现 Cowork 产品。
- C：工作结果/任务 + tutorial/template/course/mentor/service 等内容与承接词。

每个国家至少覆盖核心语言；探索语言按命中率继续；迁移走廊语言单独标记。一级行政区查询是探针，不意味着每区强行凑样本。

查询记录必须保留：查询文本、语言和语言角色、目标受众、任务家族、范围、状态、查看数量、有效结果和备注。没有结果也要记录，不能只保存命中项。

## 4. Channel Fit Pilot 与 Gate A

默认检查每个候选渠道前 20 个相关结果；没有排名结果的平台用两个等量时间批次。Core 的最低条件：

- 公开或明确授权访问，无阻塞。
- 至少两组独立查询产生有效发现。
- 能保存原文、日期和上下文。
- 国家归因可达 High/Medium。
- 能反复执行，并出现主流知识工作任务。

少量但独特的来源可做 Supplement。目录、活动页和生态名单通常为 Discovery-only。登录/API 墭强为 Auth-optional。私域群为 Consent-required。Developer 或全球技术来源最高只能做技术 Supplement。

Gate A 审核者逐流检查 A/B/C。没有 Core 时保留 `documented_gap` 和替代方案，不降证据标准。

## 5. 原始证据与编码

`raw-discovery-log.csv` 一项底层公开内容一行。只摘录支撑编码的最短必要原话与上下文，不复制全文、完整评论区或完整字幕。

A/B/C 表一行代表一个可独立判断的证据单元。同一内容可有多个不同单元，但同一句话或同一任务不能为了跨主题重复计数。每行必须回链 `content_id`。

最少保留：

- 原话、中文译文、内容语言。
- item URL、来源、作者别名、发布日期与抓取日期。
- 国家/地区、一级行政区、地域证据和置信度。
- 角色、技术层级、来源受众偏差。
- 查询 ID、发现轮次、Included/Excluded/Candidate 状态。

翻译保持含义和语气；不补猜职业、居住地、价格、点击、收入或效果。无法判断写 Unknown 或留空。

## 6. 三条证据线的入选门槛

- A 必须有具体产品、工作任务和实际结果/摩擦；纯情绪、新闻和官网证言不计。
- B 必须有工作任务、当前办法/痛点或期望结果；不要只搜产品评价。
- C 保存内容场景、平台原始指标、查询内排名、CTA、承接物和商业偏差。不同平台指标不相加；点击未知留空。

GitHub/开发者论坛可以解释集成、自动化、隐私、安全和高级工作流，但不能替代普通办公室、求职、销售、运营和小企业信号。

## 7. Gate B 与停止

首次 `validate` 会生成审核清单并因未签字 BLOCK。研究员不应自行替审核者签字。审核完成后再次验证。

若全部核心查询已尝试，但有效公开内容不足，记 WARN 并保持空白。若主流查询没做，或用技术样本填主流覆盖，记 BLOCK。

满足任一条件可停止：连续两批无新任务/角色/关键反例；达到预设时间或查询预算；匿名替代已穷尽且剩余来源均为 Auth-optional/Consent-required/Reject。停止不等于充分，报告需披露产出、饱和判断与缺口。

## 8. 交付

`build` 生成 Markdown 与十工作表 XLSX，并冻结 run。抽查至少三条标题证据：从报告 Evidence ID → 编码行 → Content ID → raw 原话 → URL。冻结后的修改新开 run。

CSV 一律 UTF-8；Excel/飞书导入时确认阿语、日语、印地语、葡语和中文不乱码。XLSX 是方便审阅的视图，CSV 和 manifest 是可重复执行的事实底座。
