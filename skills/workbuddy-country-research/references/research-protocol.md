# 逐国公开信号采集协议

## 目标与边界

每个国家 run 只交付完整、可回溯、可合并的原始数据。三条证据流是：

- A：Cowork 及类似产品在真实工作任务中的体验、成功、失败、限制、迁移与付费反馈。
- B：当地用户的工作任务、现行做法、痛点、触发因素、期望结果和付费/切换信号。
- C：KOL/KOC 围绕工作结果、教程、模板、课程、导师、服务或产品形成的内容与商业承接信号。

本阶段不回答哪个国家最好、需求规模多大、产品如何制胜或是否应进入市场。

## 研究单位

一位执行人负责一个国家。国家 run 是最小交付单位，路径为：

`research/runs/<ISO2>/<run-id>/`

地区/语区研究在国家包完成后单独运行，不把 GCC、MENA、阿拉伯语区或迁移走廊证据强行归入某国。跨境内容可保留，但必须记录 `scope_level`、`origin_market`、`destination_market` 与国家归因依据。

## 采集顺序

1. 核对国家配置：语言、行政区、人群、任务、产品和候选渠道。
2. 发现当地来源：不假设其他国家的渠道组合可直接复制。
3. 小规模 pilot：记录访问、产量、日期、原话、地域和主流任务能力。
4. 确定来源角色：Core、Supplement、Discovery-only、Auth-optional、Consent-required、Reject。
5. 执行预登记 A/B/C 查询矩阵；零命中也写回。
6. 做增量查询与两批饱和检查。
7. 写入 raw，再编码 A/B/C；不允许证据脱离 raw。
8. 运行结构校验，修复 BLOCK，保留 WARN。
9. 生成标准 ZIP；不另做总结。

## 来源角色口径

`Core` 同时要求公开合规、至少两组查询稳定命中、可保存最短必要原话与日期、具备 High/Medium 国家依据，并覆盖主流工作任务。`Supplement` 可补足独特语言、人群、地区或字段，但不能独立代表全国。`Discovery-only` 只能用于找人、找机构、找话题或找下一跳。`Auth-optional` 必须是执行人合法授权的访问，并在采集模式中明确记录。`Consent-required` 和 `Reject` 不得进入正式 Included 证据。

来源计划由本国执行人负责，不等待管理者 Gate A；每次人工调整都要写理由。`04-approved-source-plan.yml` 是旧版兼容文件名，不表示已完成独立审核。

## “尽量全”的可执行定义

“全”只指记录查询矩阵内、在当次公开可见排序和预算范围内的全部合格唯一命中。不是平台全量，不是随机抽样，也不代表人口比例。

每条查询保存：文本、语言角色、来源、地域、人群、任务、产品、状态、检查数、有效数和备注。必须记录零命中、重复密集、登录限制、分页终止和算法只展示部分结果等情况。

完成预登记矩阵后，以固定小批次追加本地词、口语词、替代产品和次国家探针。连续两批同时满足以下条件才可停止：

- 无新增合格唯一内容；
- 无新增任务家族或人群；
- 无新增关键反例。

若因时间/次数停止，写 `budget_limited`；因登录、授权或私域边界停止，写 `access_limited`；因动态排序或有限窗口停止，写 `ranking_limited`。

为便于确定性校验，在两条增量查询的 `notes` 中分别保留 `saturation_batch_1; new_unique=0; new_dimensions=0` 和 `saturation_batch_2; new_unique=0; new_dimensions=0`。如果未达到饱和，则至少在受影响查询的 status/notes 中写明上述一种限制标签，否则结构校验会 BLOCK。

## 合规和隐私

- 只访问公开页面或执行人已有合法权限的页面。
- 不绕过登录、验证码、robots、限速、付费墙或群组同意。
- 私人群、封闭社区和个人对话默认不采集。
- 只保留判断所需的最短原话，不复制整篇文章、完整评论区或完整字幕。
- 删除分类广告、招聘或服务页面中的个人电话、邮箱和不必要实名。
- 作者使用公开别名；不补全真实身份。
- 看不到的数据保持空白或 Unknown，禁止推断。

## 数据状态

`Included`：满足证据和国家归因要求，可进入 A/B/C。`Candidate`：仍需验证日期、地域、原话或任务。`Excluded`：保留发现和排除理由，但不进入正式证据。`Needs-review`：存在歧义，内部校验前需要执行人处理。

内部探索不要求 Gate B 签字。结构校验的 `PASS/WARN` 只表示数据结构与最低证据字段可用，不表示观点已被独立核实。
